Short Video Publisher

Short Video Publisher（台式摸魚 發布工具，TikTok 上的名稱為 Taishi Moyu Publisher）是創作者本人用來把自己的短影片發布到自己的 YouTube、TikTok、Instagram、Facebook 帳號的個人工具。

Short Video Publisher (also listed as Taishi Moyu Publisher) is a personal tool that publishes the creator's own short videos to the creator's own YouTube, TikTok, Instagram and Facebook accounts.

How it uses Google data

With the creator's permission, Short Video Publisher uses the YouTube Data API to upload the creator's own videos to the creator's own YouTube channel, and to read view, like and comment counts of those videos so the creator can see them in the tool. Data stays on the creator's own computer and is never sold or shared.
